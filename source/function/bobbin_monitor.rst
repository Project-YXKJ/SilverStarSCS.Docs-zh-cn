底线监控
========

底线监控分为两种： **底线计数器（BSC）** 和 **余量监视器（RTM）**，由参数 :option:`O99` 决定。

报警如何运作
------------

- 中途停止时（切线前）的无底线警告

  A65 = 0
    不停车，缝纫继续。

  A65 = 1
    停车，并且显示屏出现提示 :exc:`ExcCode010`，即使向前踩踏板也无法缝纫。

    必须在显示屏确认提示信息后，才可继续缝纫。

- 缝纫结束时（切线后）的无底线警告

  O20 = 0
    显示屏出现提示 :exc:`ExcCode052`，向前踩踏板可继续缝纫。

    之后自主选择合适的时机更换梭芯，并在显示屏上进行重置。

  O20 = 1
    显示屏出现提示 :exc:`ExcCode005`，即使向前踩踏板也无法缝纫。

    必须更换梭芯，并且在显示屏上进行重置，才可进入可缝纫的状态。

底线计数器（BSC）
-----------------

使用底线计数器可以让用户大概知道锁芯余量。

如何工作？
~~~~~~~~~~

计数器方程：

.. math::
    :name: 底线余量方程

    N_{\text{余量}}
    = O43_{\text{底线计数器复位值}} - O44_{\text{底线计数器值}}

快速入门
~~~~~~~~

以下步骤：

1. 设置合适 :option:`O19` 的值，每缝纫其设置的针数，计数值 :option:`O44` 加 1。
2. 设置合适 :option:`O43` 的值，这是个很宽泛的数值，反应你的锁芯供线能力，取决 使用的锁芯大小以及缝线的粗细。
3. 设置参数 :option:`A65` 和 :option:`O20` 来决定报警如何运作；
4. 将参数 :option:`A12` 设置为 1，打开底线监控功能。

余量监视器（RTM）
-----------------

.. versionchanged:: 90A0-v1.15.03

   加入功能。

此功能需要额外的传感器，并且为了避免信号干扰，需要一个电磁阀用于清洁传感器。

快速入门
~~~~~~~~

激活 RTM 的步骤：

1. 参考 :doc:`input_configuration`，根据实际余量监视传感器接入的端口号，修改对应的输入功能为：

        27 = 底线监控（RTM）；

2. 参考 :doc:`output_configuration`，依据清洁吹气电磁阀接入的端口号，修改对应的输出功能为：

        17 = 清洁底线传感器（RTM）；

3. 检查底线监控模式，确保 :option:`O99` 的值为 2；
4. 设置参数 :option:`A65` 和 :option:`O20` 来决定报警如何运作；
5. 设置参数 :option:`A92` 和 :option:`A93` 来决定清洁吹气如何工作；
6. 将 :option:`A91` 设置为 1，打开底线监控功能；
7. 将参数 :option:`A12` 设置为 1，打开底线监控功能。

快速参考
--------

下表总结了底线监视功能所使用到的参数：

==================== ====== =============
参数                 权限   参见
==================== ====== =============
底线监控             操作员 :option:`A12`
底线监控模式         操作员 :option:`O99`
缝纫停止             技术员 :option:`A65`
需要复位             技术员 :option:`O20`
底线计数器重置值     技术员 :option:`O43`
底线计数因子         技术员 :option:`O19`
底线计数器当前值     技术员 :option:`O44`
传感器清洁（RTM）    技术员 :option:`A91`
清洁开始针数（RTM）  技术员 :option:`A92`
吹气持续时间（RTM）  技术员 :option:`A93`
全力时间             技术员 :option:`A94`
维持出力阶段的占空比 技术员 :option:`A95`
==================== ====== =============

参数列表
------------

.. option:: A12

    -Max  1
    -Min  0
    -Unit  --
    -Description
      | 底线监控：
      | 0 = 关闭；
      | 1 = 打开

.. option:: O99

    -Max  2
    -Min  1
    -Unit  --
    -Description
      | 底线监控模式：
      | 1 = 软件，通过针数计算底线余量（BSC）；
      | 2 = 监视器，加装额外的传感器检测余量（RTM）

.. option:: A65

    -Max  1
    -Min  0
    -Unit  --
    -Description
      | 中途停止时（切线前），当锁芯余量不足时，缝纫停止并且显示报警信息：
      | 0 = 仅显示提醒；
      | 1 = 停车，并显示提醒

.. option:: O20

    -Max  1
    -Min  0
    -Unit  --
    -Description
      | 缝纫结束时（切线后），剪线后锁芯余量如果不足，缝纫将被禁止。必须进行重置方可恢复：
      | 0 = 无需；
      | 1 = 需要重置

.. option:: O43

    -Max  9999
    -Min  1
    -Unit  --
    -Description  梭芯供应能力，这是一个很宽泛的值，取决你使用的锁芯大小以及线的粗细

.. option:: O19

    -Max  200
    -Min  1
    -Unit  针
    -Description  每缝纫因子所设置的针数，计数器加 1

.. option:: O44

    -Max  9999
    -Min  0
    -Unit  --
    -Description  底线计数器当前值，预设值减去此值为余量

.. option:: A91

    -Max  1
    -Min  0
    -Unit  --
    -Description
      | 清洁（RTM）：
      | 0 = 关闭；
      | 1 = 打开

.. option:: A92

    -Max  99
    -Min  0
    -Unit  stitch
    -Description  清洁开始针数（RTM）：缝纫开始到激活传感器吹气清洁之间的针数

.. option:: A93

    -Max  9999
    -Min  1
    -Unit  ms
    -Description  吹气持续时间（RTM）：传感器吹气清洁的持续时间

.. option:: A94

    -Max  999
    -Min  1
    -Unit  ms
    -Description  传感器清洁吹气（RTM）：全力时间，:term:`时间 t1`

.. option:: A95

    -Max  100
    -Min  1
    -Unit  %
    -Description  传感器清洁吹气（RTM）：维持出力阶段 :term:`时间 t2` 的占空比
